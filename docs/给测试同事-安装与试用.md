# LanDocShare 试用说明（给测试同事）

一句话：**每人把自己的资料留在这台电脑上，别人用 AI 助手问一句就能搜到「哪句话在哪份文档里」，但拿不到原文、也不能下载。**

两种用法，按你要做的事选一种；两种都要的话就都做。

| 你想干什么 | 要装什么 | 大概几分钟 |
|---|---|---|
| 查别人的资料（大多数同事） | 只装一个 skill 包 | 3 分钟 |
| 把自己的资料开放给同事查（库主人） | 装库软件 + 建一个库 | 10 分钟 + 等它收录 |

登记中心（大家的库都在这张表里）：**http://10.91.1.197:8767/**

## 一、只想查资料：装 skill 包

1. 打开上面那个地址，点「下载 skill 包（lan-lib-search.zip）」。
2. 解压，把整个 `lan-lib-search` 文件夹放到你的 skills 目录里（不知道放哪就问一下你用的 AI 助手：「把这个 skill 装上」）。
3. 之后直接问：「谁那儿有玉田水库的资料」「院里有没有马斯京根的报告」。

包里已经写好了登记中心地址，不用再配置。查到的结果只给命中片段和表格，原文仍在对方电脑上。

## 二、要让同事能查到你：装库软件、建库

1. **拿到库软件**：从上面那个地址点「下载库软件（zip）」，或者用我发给你的 `LanDocShare-0.2.29.zip`（两个是同一个东西，从中心下的永远是最新）。
2. **解压到你有写权限的地方**，比如 `D:\LanDocShare\`。别放 `C:\Program Files`（那里不让写），也别直接在压缩包里双击。
3. **双击 `LanDocShare.exe`**。第一次会弹出「建库向导」，一共四项：
   - **库名称**：默认是你的电脑名 + 的资料库，可以改成「张三的资料库」，同事在列表里看到的就是这个。
   - **库位置**：索引放在哪，默认在「我的文档\LanDocShare」。**这里只是索引，你的原始文件不会被移动、也不会被改。**
   - **共享哪些文件夹**：点「添加」选你愿意开放的文件夹，可以选多个。**没选的文件夹同事绝对搜不到。**
   - **谁能查**：默认「仅指定名单」。名单本身在托盘右键 **授权名单…** 里加（对方的 IP 让他打开状态窗口看「服务地址」那一行）；名单还空着时，除了你自己谁都查不到。想让同网段的人都能查就改选「公司内网」；只自己用选「仅本机」。
   - **登记中心**：**已经填好了**，不用动。填了这一项，你的库才会出现在大家的列表里、有新版才会提示你。
4. 点「建库」。托盘区出现一个小图标，桌面弹出状态窗口——**第一次要等你选的文件夹被收录完**（几百篇大概十几分钟，上千篇半小时左右；状态窗口里有进度和剩余时间）。
5. 收录完，别人就能查到了。**你的电脑要开着、软件要开着**，同事才搜得到你。

### 托盘图标能干什么（右键）

- **显示状态窗口**：进度、收录篇数、谁在查、有没有新版本。
- **可访问的资料库…**：看你能查别人的哪些库，双击直接打开对方的库主页。
- **授权名单…**：维护「谁能查我」的姓名/IP 名单。名单还空着时，打开这个窗口会自动从登记中心取全院名单填进来（40 人、6 个部门），确认后点「保存并使生效」即可。
- **检查更新**：有新版时点它，软件会自己下载、重启、升级。
- **开机自启**：勾上之后每次开机它自己就在托盘里待着，同事随时能搜到；不勾也能用，只是每次开机要你自己双击打开。**第一次建库收录进文档后，它会问你一次**，答过就不再问。
- **退出**：真的退出服务。**直接点窗口的 × 只是把窗口收起来，服务还在跑。**

### 两个容易踩的点

- **Windows 第一次会弹防火墙提示**，问「是否允许 LanDocShare 在专用网络上通信」——**要点「允许」**（只勾专用网络即可）。点了取消，同事就连不上你。
- **要撤掉某个文件夹的共享**：托盘 →「修改建库设置」→ 把那个文件夹从列表里删掉。你的资料仍在、你自己还能搜，同事那边立刻就查不到了（搜索结果里会标「已撤回共享」，是给你自己看的提示）。

## 三、试用时请重点帮我试这几件

1. 建库 → 等收录完 → 让旁边的同事用 AI 助手搜一个只有你才有的词，看能不能搜到、片段对不对。
2. 搜一份**带表格**的文档，看「查看表格」里的数字对不对。
3. 托盘右键 →「显示状态窗口」和「可访问的资料库…」能不能正常弹出来。
4. 托盘右键 →「退出」，再双击 `LanDocShare.exe` 重新打开，看是否还记得你的库。
5. 第一次收录完后有没有弹「要不要让它随开机自动启动」，勾上之后重启电脑看托盘里在不在。
6. 有新版提示时点一下升级，看能不能自己装好。

## 四、出问题了怎么找我

把这两样发我，基本能定位：

- 状态窗口的截图（有报错也行）。
- 库目录下 `logs\app.log` 的最后 30 行（库目录就是向导里选的「库位置」）。

**我不会去翻你的文档内容**；日志里只有端口、篇数、访问被拒这类运行信息。
